# Dotfiles

Personal Fish, Neovim, tmux, and Hyprland desktop configuration. The desktop folders (`hypr`, `waybar`, `swaync`, `wallust`, and `wlogout`) are for Linux with Hyprland. Neovim, tmux, and Fish can also be used without the desktop setup.

## Dependencies

Run the interactive installer from the repository root. It detects Arch, Debian/Ubuntu, Fedora, or macOS and asks which groups to install. It only installs packages; it never links configs or replaces existing files.

```sh
./install-prerequisites.sh --dry-run
./install-prerequisites.sh
```

The prompts cover shell tools, Neovim and Node.js, optional C/Rust tools, and (on Arch) the Hyprland desktop stack. Arch's desktop option can also install `wallust`, `wlogout`, and `swww` through an **already installed** `paru` or `yay`, after a separate prompt. It does not install an AUR helper. Preview other package families with `--dry-run --os debian` (or `arch`, `fedora`, `macos`). The installer asks for one final confirmation before running package commands. On Arch it runs `pacman -Syu` to avoid a partial upgrade.

Neovim needs **0.12 or newer**. The installer checks the installed version and warns if a distribution package is too old; in that case install a current [Neovim release](https://neovim.io/) before using this config. The included Arch bundle installs a Nerd Font. On other systems, install a Nerd Font in the terminal separately or set `vim.g.have_nerd_font = false` in `nvim/init.lua`.

The macOS route needs [Homebrew](https://docs.brew.sh/Installation) and Xcode Command Line Tools already installed. Its optional language group installs C formatting and Rust tools; the GDB debug setup in the Neovim config is for Linux. Hyprland and its desktop dependencies are offered on Arch only. Optional applications invoked by individual desktop scripts (such as AGS, a browser, and a wallpaper picker) may need separate installation and setup.

For Neovim's language servers and formatters, see [nvim/DEPENDENCIES.md](nvim/DEPENDENCIES.md). On Debian/Ubuntu the `fd-find` binary is named `fdfind`; Neovim still works without the optional `fd` command.

## Use the configs

Clone the repository, back up any existing config directory, and link only the folders you want. For example:

```sh
git clone git@github.com:gustawalk/.dotfiles.git "$HOME/.dotfiles"
cd "$HOME/.dotfiles"
mkdir -p "$HOME/.config"
mv "$HOME/.config/nvim" "$HOME/.config/nvim.backup"
ln -s "$PWD/nvim" "$HOME/.config/nvim"
```

Repeat the backup and link steps for `tmux`, `fish`, or the desktop folders you use. Skip the `mv` command when there is no existing directory. Keep your machine's monitor layout in `~/.config/hypr/monitors.conf`; it is generated by `nwg-displays` and should be reviewed for each display setup. `fish/fish_variables` is generated by Fish and is intentionally not stored here.

Start Neovim and run `:Lazy sync`; see [nvim/README.md](nvim/README.md) and [nvim/KEYBINDS.md](nvim/KEYBINDS.md) for the editor. See [tmux/README.md](tmux/README.md) for pane and window shortcuts. To reload tmux after changing its config, press `Ctrl+b R`.
