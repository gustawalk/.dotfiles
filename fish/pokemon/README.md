# Pokémon banner sprites

Six small regular ANSI sprites from phoneybadger/pokemon-colorscripts:
https://gitlab.com/phoneybadger/pokemon-colorscripts

Copied from the installed pokemon-colorscripts-git package on 2026-10-31.
